# コンテンツのネタ調査

協会のコンテンツ（ブログ・SNS・ポッドキャスト・講座）に使う材料を、Claude Code の調査エージェントで集めて置く場所です。

## エージェント

| エージェント | 調べること | 保存先 |
|---|---|---|
| `pesticide-researcher` | 使われている農薬（成分・系統・出荷量）、毒性や環境影響の研究、残留基準の国際比較、茶の農薬、規制の動き | `research/pesticide/` |
| `fertilizer-researcher` | 使われている化学肥料（N・P・K、品目別）、国内価格と国際相場の値動きとその理由、輸入依存、政策、環境影響 | `research/fertilizer/` |
| `tea-market-researcher` | 有機栽培茶・自然栽培茶のシェアの変化（有機JAS格付量・面積・輸出・価格）、関連する記事・ブログの収集 | `research/tea-market/` |

定義は `.claude/agents/` にあります。調べる範囲や情報源を変えたいときはそこを直します。

## 使い方（Claude Code で）

- 3つまとめて：`/content-research`（テーマを絞るなら `/content-research 茶の残留農薬`）
  → 3つが同時に調べて、最後に `research/YYYY-MM-DD-netachou.md`（ネタ帳）にまとめます。
- 1つだけ：「pesticide-researcher でネオニコチノイドの最新データを調べて」のように頼みます。
- 毎朝のレポート：`/content-research daily`。新しく出た情報と、曜日ごとの深掘り1つ（月木＝農薬、火金＝肥料、水土＝お茶、日＝週のまとめ）を `research/daily/YYYY-MM-DD.md` に書きます。毎朝6時の定期実行はこれを動かし、結果を Notion の「ネタ調査」ページ（毎朝のレポート／集めた情報）にもためます。

## 調査ファイルの約束

- 1つの数字につき、出典名・URL・データの年をセットで書く。たどれなかった数字は「未確認」。
- 事実と考察を分ける。評価が割れている話は両方の立場を書く。
- 時系列データは同じ名前の `.csv` も置く（グラフ用）。
