# 悠三堂 Squareオンライン 立ち上げ一式

Square の管理画面にある「オンラインビジネス（Squareオンライン）」で、悠三堂の店を作るための材料です。
サイトそのものは Square の画面で組み立てるので、ここには **そのまま貼れる文章・商品登録の下書き表・設定の順番** を置いています。

| ファイル | 中身 |
|---|---|
| `README.md`（これ） | 作る順番とチェックリスト、デザインの決めごと |
| [`pages.md`](pages.md) | ページ構成と、各ページに貼る文章 |
| [`items-draft.csv`](items-draft.csv) | 商品登録の下書き表（Excel・Googleスプレッドシートで開けます） |

> **まだ入っていないもの**：商品名・価格・説明・写真。商品データを受け取っていないので、`items-draft.csv` は列と記入例だけです。
> 文章中の【 】は、悠三堂の実際の情報で埋める場所です。Square の料金・手数料・画面の名前は変わることがあるので、設定のときに Square の画面で確かめてください。

## 作る順番

### 1. 下準備（Square の画面に入る前）
- [ ] 商品を `items-draft.csv` に書き出す（Shopify の「商品管理 → エクスポート」のCSVをもらえれば、こちらで変換できます）
- [ ] 写真をそろえる：トップ用の横長1枚（茶畑）、商品ごとに正方形1〜3枚、畑・人の写真4〜5枚
- [ ] ロゴ（透過PNG）
- [ ] 今の店（yusando.com）の「特定商取引法に基づく表記」「送料」「返品」の文面を手元に用意する

### 2. 商品を入れる
1. Square データ（管理画面）→ **商品 → 商品ライブラリ → アクション → 商品ライブラリをエクスポート → 空白のインポートライブラリ** で、Square 公式のひな型（xlsx）を落とす
2. `items-draft.csv` の内容を、ひな型の同じ意味の列へ写す（列の対応は下の表）
3. 同じ画面の **インポート** でひな型を取り込む
4. 写真は取り込めないので、商品ごとに画面から足す

`items-draft.csv` の列と、Square のひな型の列の対応（ひな型の列名は時期や言語で変わるので、**ひな型の1行目と説明欄を正とする**）：

| 下書き表の列 | Square のひな型で探す列 | 書き方 |
|---|---|---|
| 商品名 | 商品名 / Item Name | 種類ちがい（内容量など）は同じ商品名で行を分ける |
| バリエーション名 | バリエーション名 / Variation Name | 例：リーフ 50g、ティーバッグ 2g×10P。1種類だけなら「通常」 |
| SKU | SKU | Shopify と同じ番号にすると在庫の突き合わせが楽 |
| 説明 | 説明 / Description | 商品ページの本文。事実は今の商品説明の範囲で |
| カテゴリ | カテゴリ / Category | 下の「カテゴリ案」から |
| 税込価格 | 価格 / Price | 数字だけ（円マーク・カンマなし） |
| 税率 | 税の列 | お茶など食品は軽減税率8％、酒類は10％ |
| 重さg | 重さ / Weight | ひな型は kg のことが多い。g を1000で割って入れる |
| オンライン表示 | Squareオンラインでの表示 / Square Online Item Visibility | 出す＝表示、出さない＝非表示 |
| 配送 | 配送 / Shipping Enabled | 発送する商品は「はい」 |
| 在庫数 | 新しい数量 / New Quantity（店舗名つき） | 在庫を数えない商品は空欄 |
| メモ | （取り込まない） | 自分用 |

### 3. サイトを作る
1. Square データ → **オンライン → ウェブサイトを作成**。「商品を配送で売る」型を選ぶ
2. サイト名「悠三堂」、ロゴ、色と書体を入れる（下の「デザインの決めごと」）
3. [`pages.md`](pages.md) の順にページを作り、文章を貼る
4. メニュー（上）：お茶を選ぶ ／ 悠三堂のこと ／ 淹れ方 ／ よくある質問
   メニュー（下）：特定商取引法に基づく表記 ／ 送料とお届け ／ 返品・交換 ／ プライバシーポリシー ／ お問い合わせ

### 4. 売るための設定
- [ ] **配送**：発送元の住所、送料の決め方（今の店と同じ金額にする。【一律／金額で無料／地域別】）
- [ ] **支払い**：カード決済は Square 標準。今の店で受けている **郵便振替・代引き** が Squareオンラインで選べるかは、設定画面で確かめる。選べなければ「カードのみ」と送料ページに書く
- [ ] **税**：軽減税率8％の税を作り、お茶の商品に付ける。価格は税込表示にする
- [ ] **お知らせメール**：注文確認・発送連絡の差出人名を「悠三堂」に、返信先を店の連絡用アドレスに
- [ ] **特定商取引法に基づく表記**：必ず公開前に載せる（`pages.md` の6）
- [ ] **日本酒**：酒類は年齢確認と通信販売の表示が要るので、最初はお茶だけで始めるのがおすすめ

### 5. 公開前の確認
- [ ] スマホで、トップ → 商品 → かご → 支払いの手前まで通して見る
- [ ] 1つ自分で買ってみて、注文メール・在庫の減り・Square 側の売上を確かめる（あとで返金）
- [ ] 送料が今の店と同じ金額になっているか
- [ ] 【 】が残っていないか（全ページ）
- [ ] 在庫を Shopify の店と二重に持つなら、どちらで数を合わせるか決める（Square と Shopify の在庫は自動ではつながりません）

### 6. 公開してから
- [ ] 住所（ドメイン）：はじめは Square がくれる `◯◯.square.site`。独自の住所を使うなら、今の yusando.com（Shopify の店）とぶつからない名前にする（例：`shop.` などの下位の住所）
- [ ] Instagram・YouTube・Podcast の紹介欄に新しい店のリンクを足す
- [ ] Google に店を知らせる（サイトの設定 → SEO でタイトルと説明を入れる。文面は `pages.md` の冒頭）

## カテゴリ案

商品が決まったら、要らないものは消してください。

1. リーフ（茶葉）
2. ティーバッグ
3. 抹茶・粉のお茶
4. 季節のお茶（自然花茶・はなばんちゃ など）
5. お試し
6. ギフト
7. （あとから）日本酒・コーヒー

## デザインの決めごと

今の悠三堂の特集ページと同じ見た目にそろえます。

| 項目 | 値 |
|---|---|
| 背景（生成り） | `#faf7f0`、区切りの面は `#f2ede1` |
| 文字（墨） | `#2b2a26` |
| 差し色（茶の緑） | `#4f5f3a` … ボタン、リンク |
| 飾り（金） | `#b89a5a` … 細い線、小見出し |
| 罫線 | `#e3dccb` |
| 書体 | 見出し・本文とも明朝系。Square の書体一覧に「しっぽり明朝」があればそれ、なければ Noto Serif JP など明朝のもの |
| 写真 | トップは茶畑の全面写真に白い文字。文字は写真の暗いところに置く |
| ボタン | 角の丸みは小さく、緑の地に白文字。文言は「お茶を選ぶ」「かごに入れる」 |
