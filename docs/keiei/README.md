# 経営評定（`docs/keiei/`）

自社の経営数字を、戦国シミュレーション風の画面で見渡す経営管理ツール。ビルド不要の静的サイトで、公開先は `/keiei/`（検索よけの `noindex` つき、計測タグなし）。

## 使い方

1. 初めて開くと、架空の会社「悠三堂」のサンプルで始まります（実在の数字ではありません）。
2. 下の「帳簿」で、月ごと・事業（城）ごとに 収入（売上）・原価・目標・在庫・リピート率、全社の販管費と手元資金を入れます。入力欄を離れると自動で保存されます。
3. 「帳簿」の「領地」で圃場を登録します（面積は a・反・町で入力。石高に換算して表示）。
4. 「大地図」で城（事業）と領地（圃場）を選ぶと要約が出ます。軍師の進言には、いちばん大事な注意が1件出ます。
5. 月末に「評定」で損益・予実・資金繰り予測・進言を確認し、「次の月へ」で締めます（年表に記録され、翌月は目標・在庫・リピート率・手元資金を引き継ぎます）。

データはこの端末のブラウザ（localStorage の `keiei:v1`）にだけ保存されます。端末を替えるときや念のためには「帳簿」→「バックアップ（JSON）」で書き出し、「バックアップから復元」で戻します。「サンプルに戻す」「すべて消す」は確認のあとで実行します。

## 言葉の対応

| 戦国の言葉 | 経営の中身 |
|---|---|
| 城 | 事業・販路（オンラインショップ、卸、茶道教室 など） |
| 領地・石高 | 圃場と、その面積。既定は 1反（10a）＝1万石（1a＝1,000石、1町＝10万石）。換算は「帳簿」で変更できる |
| 国力 | 総石高（全圃場の合計） |
| 収入 | 売上 |
| 金 | 手元資金 |
| 兵糧 | 在庫（金額） |
| 民忠 | リピート率（%） |
| 武将 | メンバー（統率＝マネジメント／武勇＝営業／知略＝企画／政務＝事務）。担当の城と担当の圃場を持つ |
| 知行 | 武将が担当する圃場の石高の合計 |
| 内政 | 施策（開墾＝商品開発、商業＝販促、普請＝設備、外交＝取引先、調略＝新規開拓、人事＝採用・育成） |
| 合戦・攻略ゲージ | 月の売上目標に対する実績 |
| 評定 | 月次レビュー |
| 軍師の進言 | 数字からルールで自動で出す注意・助言 |
| 次の月へ | 月次締め |
| 年表 | 月次締めの履歴 |

## CSV

- 数字の表：見出し `月,城,売上,原価,目標,在庫,リピート率,販管費,手元資金`。販管費と手元資金は城の欄を `（全社）` にした行に書く。空欄はそのまま、知らない城は新しく加える。
- 圃場の表：見出し `圃場,面積(a),作物・品種,担当,メモ`。面積は `120` のほか `1町2反` とも書ける。担当は武将の名前。
- 取り込みは同じボタンで、見出しを見て自動で見分けます。書き出しは UTF-8（BOM付き）。

## ファイル

```
index.html  style.css  app.js   画面
logic.js                        計算（損益・予実・資金繰り予測・進言・石高・CSV）。DOM を使わないので Node でも読める
sample.js                       架空のサンプルデータ
icon.svg
```

計算を直したら `node tools/check_keiei.js` で確認します。進言のしきい値は `logic.js` の `TH` にまとめてあります。
