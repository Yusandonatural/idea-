# 経営評定（`docs/keiei/`）

自社の経営数字を、戦国シミュレーション風の画面で見渡す経営管理ツール。ビルド不要の静的サイトで、公開先は `/keiei/`（検索よけの `noindex` つき、計測タグなし、外部の読み込みなし）。

畑と農業は「国取り」（圃場を広げていく）、それ以外は「商い」（城下町の店ごとの売上）として見ます。取引先・地主への書状（メール）と、部署ごとの AI への依頼文（下知状）も作れます。

## 使い方

1. 初めて開くと、架空の会社「悠三堂」のサンプルで始まります（実在の数字・名前ではありません。メールアドレスは example.com）。
2. **帳簿**：月ごと・店ごとに 商い高（売上）・原価・目標・在庫・リピート率、全社の販管費と手元資金を入れます。入力欄を離れると自動で保存。圃場の登録、石高の換算と天下取りの目標もここで変えます。
3. **国取り**：圃場（領地）の地図。「出陣」で候補地を足し、「調略を進める」で 狙い → 調略中 → 獲得 → 開墾中 → 自領 と進めます。獲得・自領になると年表に残ります。候補から外すときは「撤退」。
4. **商い**：城下町の地図。店（事業）を選ぶと商い高・目標・儲けなどが出ます。
5. **外交**：取引先・地主など（諸家）の一覧。「書状をしたためる」で型から件名と本文を作り、「メールアプリで開く」か「写す」で使います。この画面からは送信しません。送ったら「送ったと記録」。
6. **奉行所**：部署ごとの AI（奉行）に渡す「下知状」を作ります。役目・指示書・選んだ資料（今の数字）・依頼文がひとまとめになるので、写して、お使いの AI（Claude など）に貼り付けます。返ってきた答えは「報告を記録」で残せます。外交奉行の報告は「書状の下書きに使う」で外交へ渡せます。アプリが AI を自動で動かすことはなく、数字が端末の外へ自動で送られることもありません。
7. 月末に **評定** で損益・資金繰り予測・国取りの進み具合・外交の要約・進言を確認し、**次の月へ** で締めます。

スマホでは下のメニューに 評定・国取り・商い・外交 と「その他」（奉行所・内政・武将・帳簿・年表・次の月へ）が並びます。

データはこの端末のブラウザ（localStorage の `keiei:v1`。中身の版数は `v: 3`）にだけ保存されます。第1版・第2版で保存したデータはそのまま読み込み、状態を持たない圃場は「自領」として移します。念のためには「帳簿」→「バックアップ（JSON）」で書き出し、「バックアップから復元」で戻します。「サンプルに戻す」「すべて消す」は確認のあとで実行します。

## 言葉の対応

| 戦国の言葉 | 経営の中身 |
|---|---|
| 国取り・領地 | 農業：圃場を借りる・買う・開墾して広げること |
| 石高 | 圃場の面積。既定は 1反（10a）＝1万石（1a＝1,000石、1町＝10万石）。換算は「帳簿」で変更 |
| 実高・見込み・狙い | 自領（作付済み）の石高・獲得＋開墾中の石高・狙い＋調略中の石高 |
| 国力 | 実高（作付済みの圃場の合計） |
| 天下取りゲージ | 目標石高（既定100万石）に対する実高と、見込みを足した割合 |
| 狙い／調略中／獲得／開墾中／自領 | 候補地／交渉中／借りた・買った／整備中／作付済み |
| 出陣・調略を進める・撤退 | 候補地を足す・状態を1つ進める・候補から外す |
| 反収 | 10a（1反）あたりの収穫量（kg） |
| 商い・店（たな） | 農業以外の事業・販路（オンラインショップ、卸、茶道教室 など） |
| 商い高 | 売上 |
| 儲け | 粗利 |
| 蔵 | 在庫（金額） |
| 贔屓 | リピート率（%） |
| 番頭 | 店の担当 |
| 商い目標の達成・繁盛／堅調／不振 | 売上目標に対する実績・100%以上／80%以上／80%未満 |
| 金 | 手元資金 |
| 武将 | メンバー（統率＝マネジメント／武勇＝営業／知略＝企画／政務＝事務） |
| 知行 | 武将が担当する圃場（獲得・開墾中・自領）の石高の合計 |
| 外交・諸家・書状 | 取引先・地主・行政などとの連絡・その相手・メール |
| 友好度 | 相手との関係の深さ（5段階） |
| 奉行・奉行所 | 部署ごとの AI への依頼役・その一覧 |
| 下知状・下知する | AI にそのまま渡せる依頼文・それを作ること |
| 内政 | 施策（開墾＝商品開発、商業＝販促、普請＝設備、外交＝取引先、調略＝新規開拓、人事＝採用・育成） |
| 評定 | 月次レビュー |
| 軍師の進言 | 数字からルールで自動で出す注意・助言 |
| 次の月へ・年表 | 月次締め・その履歴（国取りの獲得・自領も載る） |

## CSV

- 数字の表：見出し `月,店,売上,原価,目標,在庫,リピート率,販管費,手元資金`。販管費と手元資金は店の欄を `（全社）` にした行に書く。空欄はそのまま、知らない店は新しく加える。第1版の `城` の見出しも読める。
- 圃場の表：見出し `圃場,面積(a),状態,作物・品種,担当,地主,条件,地代(年),開墾費用,収穫量(kg),メモ`。面積は `120` のほか `1町2反` とも書ける。状態は 狙い・調略中・獲得・開墾中・自領。担当は武将、地主は諸家の名前。
- 諸家の表：見出し `諸家,種別,担当者,メール,友好度,担当,最後のやりとり,メモ`。
- 取り込みは同じボタンで、見出しを見て自動で見分けます。書き出しは UTF-8（BOM付き）。

## ファイル

```
index.html  style.css  app.js   画面
logic.js                        計算（損益・予実・資金繰り予測・進言・国取り・書状・下知状・CSV・移行）。DOM を使わないので Node でも読める
sample.js                       架空のサンプルデータ（初期の奉行5人は logic.js の defaultBugyo）
icon.svg
```

計算を直したら `node tools/check_keiei.js` で確認します。進言のしきい値は `logic.js` の `TH` に、書状の型は `LETTER_TEMPLATES` にまとめてあります。
