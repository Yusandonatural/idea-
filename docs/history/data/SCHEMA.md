# 日本史アプリ 教材データの形式

1単元 = 1ファイル（`docs/history/data/u01.js` 〜 `u15.js`）。中身は `HIST.addUnit({...})` を1回呼ぶだけ。
編集したら `node tools/check_history.js` で形式チェック。

## レベル（lv）

| lv | 対象 | 目安 |
|---|---|---|
| 1 | 小学6年 | 教科書の42人物・代表的なできごと。漢字の用語はやさしく |
| 2 | 中学 | 中学歴史の教科書・高校入試レベル |
| 3 | 高校 | 日本史探究・大学入学共通テストレベル |
| 4 | 受験 | 国公立二次・難関私大（早慶・MARCH・関関同立）レベル |

アプリは「通史を4周」する。1周目は全単元を lv1 で、2周目は lv2 で…と進む。lv2 のレッスンには lv1 の復習も少し混ざる。

## 形

```js
HIST.addUnit({
  id: "u01",                       // ファイル名と同じ
  title: "旧石器・縄文・弥生",        // 短く
  period: "約3万年前〜3世紀",
  emoji: "🏺",
  intro: {                         // レッスン前に読む「まとめカード」。各レベル3〜5文。そのレベルで覚える要点
    1: "…", 2: "…", 3: "…", 4: "…",
  },
  facts: [                         // 4択問題のもと。各レベル12問以上（lv3は15問以上）
    { lv: 1, q: "米づくりが広まったのは何時代？", a: "弥生時代", d: ["縄文時代", "古墳時代", "飛鳥時代"], e: "大陸から伝わった稲作が、弥生時代に西日本から東日本へ広まった。" },
  ],
  events: [                        // 年代並べ替え問題のもと。各レベル6件以上
    { lv: 1, y: -300, when: "前4世紀ごろ", t: "稲作が広まる" },
  ],
  pairs: [                         // 組み合わせ問題のもと。各レベル6組以上
    { lv: 1, l: "卑弥呼", r: "邪馬台国の女王" },
  ],
});
```

### facts
- `q`：問い。答えが1つに決まる聞き方にする（「〜のひとつは？」のように別解がありうる聞き方は、d に正解になりうるものを入れない）。
- `a`：正解。ボタンに入るので短く（目安15字以内、lv3・4 の文章選択は40字以内）。
- `d`：まちがいの選択肢を3つ以上。a と同じ種類（人物なら人物、年なら年）で、もっともらしいが明確にまちがいのもの。4つ以上書くと毎回3つを選んで出す。
- `e`：答えたあとに出す解説。1〜2文。覚え方や前後関係がわかると良い。
- 年号を聞く問題は `a` を「1192年」のように書く。
- 定説が分かれるもの（鎌倉幕府の成立年など）は、問い方を工夫するか解説で触れる。

### events
- `y`：並べ替え用の数値。紀元前はマイナス。同じレベルの中で同じ年を作らない（同じ年は月で小数にしてもよい：1868.1）。
- `when`：答え合わせのときに表示する文字（「645年」「前1世紀」など）。
- `t`：できごと（20字以内）。

### pairs
- `l` と `r` は1対1で、同じレベル・同じ単元の中で取り違えようがないものにする（`r` どうしが似すぎないように）。`l` は人物・用語、`r` は短い説明（20字以内）。
