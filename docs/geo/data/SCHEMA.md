# 地理アプリ 教材データの形式

1単元 = 1ファイル（`docs/geo/data/u01.js` 〜 `u16.js`）。中身は `HIST.addUnit({...})` を1回呼ぶだけ。
編集したら `node tools/check_history.js --dir docs/geo/data` で形式チェック。
アプリ本体は日本史版・世界史版と共通（`docs/history/app.js`）。

## レベル（lv）

| lv | 対象 | 目安 |
|---|---|---|
| 1 | 小学 | 小5社会（日本の国土・気候・農業・工業）と、だれでも知っておきたい世界の基本 |
| 2 | 中学 | 中学地理・高校入試レベル |
| 3 | 高校 | 地理総合・地理探究・大学入学共通テストレベル |
| 4 | 難関大 | 国公立二次・MARCH・関関同立レベル（統計の読み取り、地誌、理由の説明） |
| 5 | 早慶 | 早稲田レベル。統計の読み取り・地誌の細部・2文の正誤判定・理由の説明 |

アプリは「5周」する。1周目は全単元を lv1 で、2周目は lv2 で…と進む。

## 形

```js
HIST.addUnit({
  id: "u01",
  title: "地図と地球",
  period: "緯度・経度・時差・地図",   // 単元の副題（短く）
  emoji: "🧭",
  intro: { 1: "…", 2: "…", 3: "…", 4: "…", 5: "…" },   // 各レベル3〜5文のまとめ
  facts: [
    { lv: 1, q: "日本の標準時子午線は東経何度？", a: "東経135度", d: ["東経120度", "東経140度", "東経150度"], e: "兵庫県明石市を通る東経135度が日本の標準時の基準。" },
  ],
  events: [   // ならべかえ問題のもと。k が「何の順か」。y の小さい順が正解
    { lv: 1, k: "北にあるじゅん", y: -45.5, when: "北緯45度", t: "宗谷岬" },
  ],
  pairs: [ { lv: 1, l: "やませ", r: "東北の太平洋側に吹く冷たい風" } ],
});
```

### facts
- `q` 問い／`a` 正解（目安15字以内、lv3・4 は40字以内）／`d` まちがいの選択肢3つ以上（同じ種類・明確にまちがい）／`e` 解説1〜2文。
- 各レベル 12問以上（lv3 は15問以上）。

### events（ならべかえ）
- 同じ `k` のものどうしで並べかえ問題を作る。**`y` の小さい順が正解**なので、「大きいじゅん」「多いじゅん」「北にあるじゅん」はマイナスの値を入れる（例：人口14億人 → y: -1400000000、北緯45度 → y: -45）。
- `k` は「〜じゅん」で終わる短い文（例：「北にあるじゅん」「面積が大きいじゅん」「人口が多いじゅん」「標高が高いじゅん」「東にあるじゅん」）。
- `when` は答え合わせで出す値（「約14億人」「北緯45度」「3776m」）。`t` は地名・項目。
- 各レベル 6件以上。同じ `k` は1レベルの中で3件以上そろえる（4件以上が理想）。同じ lv・k の中で y を重複させない。差が小さく統計の年で順位が入れ替わるものは使わない。

### pairs
- `l`（地名・用語）と `r`（短い説明・20字以内）を1対1で。各レベル6組以上。同じレベル・単元の中で取り違えようがないものに。

### 統計について
- 生産量・人口などの順位は、年によって入れ替わらない、はっきりした差のあるものだけを使う。
- 解説に「（2020年代の統計）」のように時点を書く。

### lv5（早慶）の書き方
- facts は1単元20問以上。用語集の頻度が低めの語、人物の著作・業績、文化史、制度の細部、テーマ史（土地制度・貨幣・外交・宗教・女性史など）を入れる。
- **2文の正誤問題**を各単元4問以上：`q` に「a: 〜。\nb: 〜。\nこの2文の正誤の組み合わせは？」（\n で改行）、`a` は「aのみ正しい」「bのみ正しい」「両方正しい」「両方誤り」のどれか、`d` に残りの3つ。誤文は一か所だけをすり替えた、まぎらわしいが明確にまちがいの文にする。
- **史料・資料問題**を各単元2問以上：短い史料の一節（30〜80字、原文か教科書・史料集の読み下し）を `q` に「」で引き、出典・人物・時期などを問う（地理は統計値や雨温図の特徴を文章で示して国・都市を問う）。
- `a`・`d` は40字以内。`q` は長くてよい（160字以内）。
