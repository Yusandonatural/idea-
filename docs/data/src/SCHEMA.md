# 意味リスト 入力スキーマ（エージェント共通）

ファイル: JSON配列（UTF-8）。1要素 = 1項目。

{
  "no": "101",              // 文字列3桁。カテゴリの百の位: 1=つなぐ技術 2=自分のこと 3=好き嫌い・気持ち 4=予定と過去 5=頼む・質問 6=旅先 7=困ったとき
  "cat": "connect",         // connect | self | feel | plan | ask | travel | trouble
  "ja": "もう一度言ってもらえますか",   // 日本人が実際に口にしたい自然な日本語。差し替え部分は ○○
  "pri": 3,                 // 優先度 3=★★★(1ヶ月目) 2=★★(2ヶ月目) 1=★(3ヶ月目)
  "slot": null,             // ○○ がある場合の差し替え語の種類（下の一覧から1つ）。なければ null
  "self": false,            // 受講者が自分の答えを入れる項目なら true（自己紹介・仕事・家族・趣味など）
  "zh": "能再说一遍吗？",    // 中国語（簡体字・普通話・口語として自然なもの）。○○ は日本語と同じく ○○ のまま残す
  "py": "Néng zài shuō yí biàn ma?",  // 声調記号つきピンイン。変調後ではなく辞書形（一・不 は実際の変調を反映：yí biàn, bú shì）
  "note": ""                // 任意。使い方の注意（30字以内）。不要なら ""
}

slot の種類（これ以外を使わない）:
place 場所 / food 食べ物 / drink 飲み物 / thing 物 / job 仕事 / hobby 趣味 / family 家族 / country 国 / city 都市 / language 言語 /
time 時刻・時間帯 / day 日・曜日 / number 数 / transport 交通手段 / activity すること / symptom 症状 / person 人 / word 単語（任意の語）

ルール:
- 教科書の例文ではなく、旅行者・ビジネスで中国語圏の人と話す日本人が「言いたくなる」ことを選ぶ
- 1項目は短く。言い切れる長さ（中国語で12字前後まで）
- ○○ は1項目につき最大1つ
- 同じ意味の重複を作らない
- 優先度の目安: 会話が止まらないため・初日から使うもの=3、あると会話が広がる=2、知っていると便利=1
