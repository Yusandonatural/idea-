# 動詞・副詞リスト 入力スキーマ

JSON配列。1要素 = 1語。

{
  "rank": 1,                 // 会話での頻度順（1が最頻出）。重複なし、1から連番
  "zh": "是",                // 簡体字
  "py": "shì",               // 声調記号つきピンイン（辞書形。一・不 は単語内で実際の変調を反映: yídìng, búyào）
  "ja": "〜である",           // 日本語の意味（短く。主な意味を1〜2個、「、」区切り）
  "group": "存在・判断",      // 意味グループ（下の一覧から1つ）
  "ex": ["我是日本人。", "Wǒ shì Rìběnrén.", "私は日本人です。"],  // 例文 [中国語, ピンイン, 日本語]。日常会話で使う短い文（12字前後まで）
  "note": ""                 // 任意。使い分けの注意（25字以内）
}

ルール:
- 普通話の口語で、日常会話の頻度が高いものから並べる（HSK1〜4程度が中心、書き言葉専用の語は入れない）
- 例文は自然で短く、意味リストの場面（自己紹介・買い物・移動・食事・予定・気持ち・困ったとき）に寄せる
- 例文のピンインは一・不の変調を反映、第3声の変調は反映しない
- 2字の動詞（学习、喜欢、工作など）や離合詞（见面、睡觉）も動詞に含めてよい
