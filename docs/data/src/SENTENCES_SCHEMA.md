# 例文バンク 入力スキーマ

JSON配列。1要素 = 1文。

{
  "id": "v12-1",                       // 対象語のID + "-" + 連番（v=動詞, a=副詞, j=形容詞。番号は各リストの rank）
  "focus": "v12",                      // この文が練習する語のID
  "zh": "我今天特别想喝热茶。",
  "py": "Wǒ jīntiān tèbié xiǎng hē rè chá.",
  "ja": "今日はとても温かいお茶が飲みたい。",
  "tokens": ["我", "今天", "特别", "想", "喝", "热", "茶", "。"],
  "level": 2
}

必須ルール:
- tokens をつなげると zh と完全に一致する（句読点も1トークン。文末の。！？も別トークン）
- tokens は「語」で区切る：2字語はまとめる（今天・喜欢・咖啡・一起）、量詞句は分ける（一 / 杯）、助詞は分ける（了・的・吗・吧・呢・过・着・得）、一下・一点儿・有点儿 はまとめる
- 対象語（focus の語）が tokens の中にそのままの形で1回は出る（離合詞で分かれる場合は避けた文にする）
- 副詞を必ず1つ以上入れる（很・非常・特别・真・太・挺・比较・最・也・都・还・就・才・又・再・已经・马上・一直・经常・常常・一起・先・刚・只・有点儿・一定・可能・大概 など）。自然なら形容詞も入れる
- level 1 = 8字以下、level 2 = 9〜13字、level 3 = 14〜18字（句読点を除いた字数）
- 普通話の自然な口語。日本人が旅行・仕事・日常会話で実際に言いそうな内容（自己紹介、お茶、食事、買い物、移動、天気、予定、気持ち、仕事）
- ピンインは声調記号つき。一・不 の変調を反映、第3声の変調は反映しない。語の区切りは tokens に合わせてスペース
- ja は自然な日本語（直訳調にしない）
- 同じファイル内で zh が重複しない。同じ語の文どうしは場面を変える
