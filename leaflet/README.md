# 悠三堂リーフレット（2026-11）

`out/` に入稿用PDF、`out/preview/` に確認用の画像があります。

| 種類 | 仕上がり | 面 | 主な使い道 |
|---|---|---|---|
| 三つ折りA4 | 297×210mm（巻き三つ折り） | 両面 | イベント・店頭・取引先 |
| チラシA4 | 210×297mm | 片面 | イベント配布 |
| はがきカード | 100×148mm | 両面 | 商品に同梱 |

それぞれ日本語版と英語版があります。

## 入稿のしかた
- PDFは上下左右に塗り足し3mmつき。トンボは付けていない
- 色はRGB。印刷所でCMYKに変換されるため、緑が少し沈むことがある
- 三つ折りは1ページ目が外面（左から 折り込む面97mm／裏表紙100mm／表紙100mm）、2ページ目が中面

## 印刷の前に確かめること
- 淹れ方の数字（茶葉の量・温度・時間）は一般的なめやす。悠三堂の数字に直す
- お茶の一覧と分け方（定番／新しいお茶／番茶）
- 英語の住所の読み（Kamifukawa-cho）
- QRコード3つ（yusando.com、yusando.com/en、YouTube @yusando）をスマホで読む
- ロゴは幅444pxの画像を使っている。大きく刷るなら元データ（ai）に差し替える

## 作り直す
```bash
cd src
python3 fetch_fonts.py   # 初回だけ。フォントを src/fonts に取得
python3 build.py         # 文章は build.py の T を直す
node render.js           # out/ にPDFと画像を書き出す
```
