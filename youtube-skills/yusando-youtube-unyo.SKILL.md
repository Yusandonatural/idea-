# 悠三堂 YouTube運用スキル

YUSANDO CHANNEL（@yusando）の、公開後の分析・改善・ショート運用の手順。編集作業そのものは別スキル（対談動画編集）を使う。

## 基本情報
- メインチャンネル：YUSANDO CHANNEL（チャンネルID UC5SrJd_wSwDzHqEMYcwRmGA）。isozaki@yusando.com は管理者
- サブチャンネル：YUSANDO VLOG（@Vlog_Yusando）。2026-11-19から、お茶作りの回・礒崎さん自身の回もメインチャンネルで公開する方針（VLOGは使わない）
- 本業は年商約3,000万円の茶農家。YouTubeは副業として、対談中心（月1日収録→4本）で回す
- 【表現ルール】政府や誰かを批判する内容・否定的な言い方は入れない。不安をあおる言葉も使わない。タイトル・概要欄・字幕・コメント返信すべてで確認する
- 作業はClaude in Chrome（パソコンのChrome）でYouTube Studioを操作する。スマホからはChromeにつながらないので、その場合は手元の数字で推定し、パソコンで確認し直すと伝える
- 視聴者は55〜64歳の男性が中心、98%が日本

## 目標と毎月見る数字
- 最終目標：広告収入で年100万円以上（月約8.3万〜10万円）。必要なのは長い動画で月15万〜20万回（1,000回あたり400〜550円の場合）。目安は1万回再生の動画を月20本前後
- 広告以外：YouTube経由で年1,000万円（ストア・お茶・茶畑ツアー・LINE公式からの販売など）。概要欄・終了画面からLINE公式へ誘導する
- 段階：2027年5月 月1万円 → 2027年11月 月3万円 → 2028年中 月8.3万円
- 広告以外も合わせて考える：商品（初霜など）、出演者の商品、メンバーシップ
- 毎月初めに見る3つ：①長い動画の月間再生数 ②1,000回あたりの収益（目標500円以上）③登録者数（1万人が目安）

## 投稿の型
- 長い動画：週2本（例：火曜＝やり方の回、金曜＝対談・考え方の回）。最低でも週1本
- 長さは10〜15分が基本（半分くらいまで見てもらえる）。20分以上は「総集編」扱い
- ショート：週4本前後。本編1本からショートを2本切り出し、2本とも本編につなげる
- 内容の割合（2026-11-19〜）：対談2本に対して、お茶作りの回・礒崎さんの回を1本の目安
  - お茶作りの回は「お茶の農法の回」として作る（自然栽培の茶畑の手入れ・考え方。商品紹介は概要欄で）
  - 礒崎さんの回は一人語りにせず、聞き手を付けた対談の形で撮る
  - 評価：初日500〜2,000回なら合格。再生数だけでなく、ストア・ツアー・LINE公式への流入も見る
- 商品紹介の回は月2回程度。売り込みではなく「できるまでの話」「淹れ方・食べ方」「季節の案内」の型で
- 伸びる型：経験の長いゲスト（橋本進さん・川口聖也さんのシリーズ）、農法の話、10〜15分、続けて公開すること。タイトルは「意外な一言」をゲストの言葉から取る（例「草取りより段取り」「時間が耕す」）。あおる言葉・否定の言葉（「崩壊」「やめろ」「危険」など）は新しい動画では使わない
- 1万回の目安：公開24時間で約2,000〜3,000回。初速はおすすめ（ホーム）からの流入が中心

## 2つの役割と毎日公開（2026-11-23〜）
- 毎日1本（1日2本以上は出さない。同じ日に出すと見る人が分かれる）。公開時間は毎日同じにする。2週間分を作り置きしてから始める
- 1週間7本の目安：対談・悩み別の切り出し・総集編＝5本（新しい人を呼ぶ・広告）／語り・お茶の回＝2本（悠三堂のファンを作る・売上）。語り・お茶の回は曜日を決めてシリーズにする
- 評価の数字を分ける
  - 対談系：24時間・48時間の再生、1万回超えの本数。合格は24時間2,000回
  - 語り・お茶：高評価の割合（2%以上）、コメントの内容、登録者の増え方、LINE登録・ストア流入（UTM付きリンク）。合格は24時間500回以上
- 語り・お茶の回の終わりと概要欄に、毎回同じ形の案内（お茶のストア・LINE公式）を添える。売り込みにしない
- 対談の終わり・概要欄から語りの回につなげる
- 語りは「1人語り」と「聞き手付き」を交互に試す
- 伸びる型（自然栽培の分野・2026-11調べ）：作物＋悩みを題名の頭に書いて答える回（検索から長く見られる）、季節の「今やること」、実験・比較、定点の畑ツアー。稲作の回は1〜2月に出す
- 見直し：毎日公開を2週間続けて新作の多くが24時間500回未満なら週4〜5本に減らす

## 公開時・公開後のチェック
1. タイトルはゲストの意外な一言を使い、検索される言葉（稲作 コツ、自家採種 など）を入れる。批判・あおりになっていないか確認
1-2. 字幕は日本語＋英語のバイリンガル（全動画・ショート含む）。YouTubeに日本語・英語の字幕ファイルをアップし、タイトルと概要欄の英語訳も登録する
2. 最初の30秒に出演者の名前テロップ
3. 概要欄の一番上に商品リンク。チャプターを付ける。仮の文字（[本のリンク] など）が残っていないか確認
4. 8分以上はミッドロール広告オン。広告オフの動画がないか確認
5. 同じゲストの回は再生リストにまとめる
6. 固定コメントに商品リンクを置く（YUSANDO CHANNELの名前で投稿されているか確認してから固定）
7. A/Bテスト実行中はタイトルを触らない

## 分析のしかた
- 動画ごと：Studio → 動画 → アナリティクス（概要）。見る項目は視聴回数、平均視聴時間と割合、登録者の増減、クリック率、見つけられ方（おすすめ・関連動画・その他）、推定収益
- 動画の比較：アナリティクス → 収益 → 詳細モード → 期間（過去365日・全期間）→ 内訳「コンテンツ」
- 評価の目安：クリック率6%以上は良い、平均視聴が50%前後なら良い、約100回の再生で登録者1人なら高い
- 新作は公開2〜3日が山。そのあと長く見られる動画（常識崩壊・土がきれいになれば など）は月300〜450円ずつ稼ぎ続ける
- 収益は1〜2日遅れてStudioに出る。当日の数字は推定と伝える
- ショートから本編への流入は多く見ても本編の再生の1割ほど。ショートの価値は新しい人に見つけてもらうこと（登録者増）

## Studioの操作のコツ
- パソコンはMac。全選択などはcmdキー（ctrlでは効かない）
- 概要欄の一番上に足すときは、説明欄のテキストの先頭にカーソルを置いてから入力する。全部書き換えるときは説明欄の中身を選択してから入力する
- 保存後は「変更を保存しました」が出たか、開き直して中身を確認する
- 編集を間違えたら「変更を元に戻す」で保存前の状態に戻す
- 昔のショートは消さない（説明欄と関連動画を足すだけで十分）
