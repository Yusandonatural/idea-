# コンテンツのネタ集め（3エージェント同時調査）

## 手順

1. 引数（テーマ）を読む。
   - テーマがなければ、3つとも全体を調べる。
   - テーマが1つの分野だけに関係するなら（例「肥料の値段」）、そのエージェントだけ動かす。
   - 複数にまたがるなら（例「お茶」）、それぞれの分野から見たテーマに言い換えて渡す（農薬→茶で使われる農薬と残留基準、肥料→茶の窒素施肥と肥料費、市場→有機茶のシェア）。
2. 次のサブエージェントを **1回のメッセージでまとめて** 起動し、同時に動かす：
   - `pesticide-researcher`（農薬）
   - `fertilizer-researcher`（化学肥料）
   - `tea-market-researcher`（有機栽培茶・自然栽培茶の市場と記事）
   各エージェントには、テーマ・今日の日付・「前回の調査ファイル（research/<分野>/ の最新）があれば読んで、新しく変わった所を中心に」と伝える。
3. 全員の結果がそろったら、`research/YYYY-MM-DD-netachou.md`（ネタ帳）を作る：
   - 今回いちばん使える数字トップ5（出典つき）
   - 分野をまたいだネタ（例：「肥料が高くなった今、無肥料の自然栽培茶は？」「輸出が伸びる有機抹茶と、海外の残留農薬基準」）
   - ネタ案を媒体別（ブログ・SNS・ポッドキャスト）に並べ、各3〜5本
   - 確認が足りない数字・注意点の一覧
   - 各分野の調査ファイルへのリンク
4. ユーザーには、ネタ帳のパスと、いちばん面白いネタ3つを短く伝える。

## 守ること

- 数字には必ず出典と年をつける。出典のない数字はネタ帳に入れない。
- 健康被害や効果を断定しない。評価が割れている話は「割れている」と書く。
- 「無農薬」「自然栽培」などの表示に関わる言葉は、使うときの注意を添える。

## 毎朝のレポート（引数が `daily` のとき）

毎朝の定期実行用。全部を一から調べ直すのではなく、**新しく出た情報**と**日替わりの深掘り1つ**に絞る。

1. `research/daily/` の直近のレポートと、各分野の最新の調査ファイルを読み、すでに書いたことを把握する。
2. 3つのエージェントを同時に起動し、それぞれに次を頼む：
   - 直近3日（月曜は直近4日）に出たニュース・発表・統計の更新・記事・ブログを探す。前のレポートに出たものは除く。
   - 新しいものが無ければ「新しい動きなし」と返してよい（無理に埋めない）。
   - 今日が深掘りの担当日なら、下の表のテーマで1つ深く調べて、その分野のフォルダに保存する。
3. 日替わりの深掘り（日本時間の曜日）：

   | 曜日 | 深掘りする分野 |
   |---|---|
   | 月・木 | 農薬（pesticide-researcher） |
   | 火・金 | 化学肥料（fertilizer-researcher） |
   | 水・土 | 有機栽培茶・自然栽培茶（tea-market-researcher） |
   | 日 | 深掘りなし。1週間分のレポートを読み返し「今週のまとめ」とネタのランキングを作る |

   深掘りのテーマは、前回までに扱っていない所を選ぶ（例：茶の残留農薬基準の国際比較、肥料の輸入先の変化、有機抹茶の輸出）。
4. `research/daily/YYYY-MM-DD.md` に朝のレポートを書く：

   ```markdown
   # 朝のネタレポート YYYY-MM-DD（曜日）

   ## 今日のひとこと（いちばん使えるネタ1つ、3行で）
   ## 新しい動き
   ### 農薬
   ### 化学肥料
   ### 有機栽培茶・自然栽培茶
   （各項目：日付／見出し／何が新しいか1〜2行／出典URL。無ければ「新しい動きなし」）
   ## 今日の深掘り：<テーマ>（要点5行と、詳しいファイルへのリンク）
   ## すぐ使えるネタ案（3〜5本：タイトル案／媒体／使う数字と出典）
   ## 確認が必要なこと
   ```
5. 最後に、レポートの「今日のひとこと」と「すぐ使えるネタ案」をそのまま返事として出す（通知で読めるように）。
